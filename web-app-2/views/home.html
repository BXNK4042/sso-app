1. Single Sign-On (SSO)

ใช้บัตรผ่าน JWT Token เดียวกันกับ Web App 1 (จองแล็บ) เมื่อล็อกอินแล้วสามารถข้ามมาใช้งานแอพนี้ได้ทันที

2. Role-Based Access

แยกสิทธิ์การยืม-คืนตาม Role ใน Token: นักศึกษา/อาจารย์ยืมได้ตามโควต้า ส่วน Admin มีสิทธิ์ตรวจสอบและบังคับคืน

3. Independent SQLite Table

จัดเก็บรายการอุปกรณ์ใน SQLite ตารางเดี่ยว `equipments` แยกส่วนอย่างเป็นอิสระและมีความปลอดภัยสูง
